欢迎使用你的新博客！这是搭建时自动生成的示例文章，用来展示 Markdown 的排版效果。看完后可以删掉它（删除 `source/_posts/hello-world.md` 后再执行 `npm run pub` 即可）。

## 常用排版示例

### 文字样式

普通文字中可以使用 **加粗**、*斜体*、`行内代码`、~~删除线~~，以及[链接](https://hexo.io/zh-cn/)。

### 列表

无序列表：

- 只需要写 Markdown 文件
- 网页自动生成并发布上线
- 手机、电脑都能正常访问

有序列表：

1. 用任何编辑器写 `.md` 文件
2. 执行 `npm run pub` 发布
3. 约一分钟后线上自动更新

### 引用

> 种一棵树最好的时间是十年前，其次是现在。

### 代码块

```js
// 代码块自带高亮和右上角复制按钮
function hello(name) {
  console.log(`Hello, ${name}!`);
}
hello("world");
```

### 表格

| 功能 | 命令 | 说明 |
| --- | --- | --- |
| 新建文章 | `npm run new "标题"` | 在 `source/_posts/` 生成 .md 文件 |
| 本地预览 | `npm run server` | 浏览器打开 http://localhost:4000 |
| 发布上线 | `npm run pub` | 推送后 GitHub 自动构建 |
